## 一、Windows 主机

### 前置（一次性）
1. **VSPD Pro** 建一对虚拟串口 `COM1 ⇄ COM2`
2. **Sunshine** 已安装（服务 `SunshineService`）
3. 游戏配置：
   - `Package/mai2.ini` → `DummyTouchPanel=0`
   - `Package/AquaMai.toml` →
     ```toml
     [GameSystem.TouchPanelPort]
     PortName_1P = "COM1"
     [GameSystem.TouchToButtonInput]   # 菜单里分区=按键，长按 C1/C2=Select(刷Aime卡)
     [GameSystem.Window]
     Width = 1080
     Height = 1920
     ```
   - `Package/segatools.ini`（MuNET）
     ```ini
     [dns]
     enable=1
     Default=play.mumur.net
     AimeDB=aime.mumur.net
     [netenv]
     enable=1
     addrSuffix=103          ; 机台号，要和 MuNET 面板上登记的一致
     [keychip]
     enable=1
     platformld=ACA1
     id=A611-03186083437    ; MuNET 面板给的机台 ID
     subnet=192.168.0.0
     gameId=SDEZ            ; 必须和游戏版本一致（SDEZ 1.70 = FESTiVAL）
     region=4
     ```

### 一键启动
```
双击 start-all.bat
```
它依次做：检查 COM1/COM2 → 起桥接（1000Hz）→ 起 Sunshine → 起 HUD → 起游戏。
关闭：`stop-all.bat`

## 二、Surface (Linux)

```bash
~/mm-start.sh     # 起 mm-panel（独占触屏）+ 面板自动隐藏 + 全屏串流
~/mm-stop.sh      # 关闭
```

调映射（主机 1080x1920 像素坐标）：
```bash
python3 ~/setmap.py                    # 看当前值
python3 ~/setmap.py --cy 1380 --r 560  # 往下/放大
python3 ~/setmap.py --rot 90           # 换旋转
```

## 三、MuNET 配置（网页端，需要你的账号）

1. 打开 https://www.mumur.net （Edge）
2. 注册/登录 → **机台管理** → 新增机台，记下：
   - 机台 ID（填到 `segatools.ini` 的 `[keychip] id=`）
   - 机台号/后缀（填到 `[netenv] addrSuffix=`）
3. **Aime 卡管理** → 新增虚拟卡，记下卡号（20 位）
   - 游戏里登录时，长按触摸板圆心（C1/C2 ≥500ms）= Select = 刷这张卡
4. 游戏内 `Test 模式`（AquaMai KeyMap `Test=ScrollLock`）→ 网络测试可看是否连上 MuNET

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 触摸没反应 | `systemctl status mm-panel`；`~/setmap.py` 调几何；HUD 看有没有命中 |
| 分区位置偏 | `~/setmap.py --cy/--r/--rot` 微调，HUD 会实时跟着变 |
| 游戏里 UI 只认按键 | 正常：菜单用 `TouchToButtonInput`，分区=Button1~8，长按圆心=Select |
| 串流不进全屏 | 检查 KDE 窗口规则里 **不要**有 `fullscreen=false` 的规则（本项目已清理） |
| 双输入（鼠标+分区） | mm-panel 崩溃会导致独占释放，看 `systemctl show mm-panel -p NRestarts` |
| **刷不上卡 / 登录退回** | `segatools.ini` 里 **`dipsw1=0`**（在线模式）。=1 是独立模式，不连服务器，读卡必失败 |
| 卡号在哪 | `Package\DEVICE\aime.txt`（segatools 生成，20 位）。要在 MuNET 面板绑定这张卡 |
| 改了 ini 后游戏黑屏/amdaemon 退出 | ini 被写入了 BOM。必须用 **UTF-8 无 BOM** 保存（前 3 字节不能是 EF BB BF） |
| 重启后串口全消失（CM_PROB_PHANTOM） | VSPD 内核驱动没起来：管理员 `sc start evserial9` |
